This Github Repository contains the software that needs to be installed in order to complete the STM32C5 workshop. This workshop requires STM32CubeMX2, STM32CubeProgrammer, and VSCode with the STM32CubeIDE for VSCode extension installed. STM32CubeMX2 and VSCode require packs and bundles respectively. These can be installed through the application with an internet connection or offline by downloading the files into the correct location. 

## Prerequisites

Before installing, ensure you have:

- Windows® (10 or later, 64 bits (x64)), macOS® (15 or 26), or Linux® (Ubuntu® 22.04, Ubuntu® 24.04, Ubuntu® 26.04, Fedora® 43 and Fedora® 44
- 4 GB of system memory (RAM)
- 7 GB of available disk space
